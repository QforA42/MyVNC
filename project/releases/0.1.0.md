# 0.1.0

**Date:** 2026-08-15
**Commit range:** N/A — this is the first version bump in the repository; there was no earlier
commit to delimit against. From this release on, `BASE_EXCLUSIVE..RELEASE_INCLUSIVE` applies as
described in [CONTRIBUTING.md](../../.github/CONTRIBUTING.md#versioning).

## Summary

The first coherent version of MyVNC: a custom-built VNC client (WPF/.NET, with the RFB protocol
implemented from scratch) for connecting to omarchy/Hyprland hosts via wayvnc, intended as a
replacement for TigerVNC.

## Changes

See [CHANGELOG.md](../../CHANGELOG.md#010---2026-08-15) for the full list.

## Upgrading

There is no earlier version to upgrade from. Build and install as described in the
[README](../../README.md) (or run `dotnet build MyVNC.slnx -c Release` and start the Release
executable).

## Risks

- ZRLE decoding is new in this version and has been verified against the protocol specification
  and a clean build, but not yet fully against a live wayvnc connection in this repository.
- There is no automated test suite; verification is manual against real omarchy hosts.

## Verification

- `dotnet build MyVNC.slnx` (Debug) and `dotnet build MyVNC.slnx -c Release` both green.
- The app starts and stays up without crashing (smoke test).
- A manual functional test against a real omarchy/wayvnc host is recommended before the release
  is considered fully verified.
