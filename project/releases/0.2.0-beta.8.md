# 0.2.0-beta.8

**Date:** 2026-08-15

## Summary

A new "Wake" button in the session toolbar, next to Ctrl+Alt+Del.

Background: on <hostname> it was not possible to wake a DPMS-blanked screen just by clicking in
the MyVNC session — only the Ctrl+Alt+Del button worked. Examined Quickshell's own
`LockView.qml` on <hostname> (via SSH) and confirmed that the lock screen's `MouseArea` actually
*does* have click-to-wake handling (`onClicked`/`onPositionChanged` both call `wakeRequested()`)
— so Quickshell itself does not ignore clicks. The conclusion: wlroots-based compositors
(Hyprland included) stop delivering pointer events entirely while the screen is DPMS-blanked,
before the event even reaches client programs such as Quickshell's lock screen — only keyboard
input gets through. Ctrl+Alt+Del only "worked" because it happens to be a keyboard command, not
because of any special meaning of that particular combination (Hyprland/omarchy has no default
binding for Ctrl+Alt+Del).

Solved with a clean, harmless approach: a single Shift press (down+up), which wakes the screen
without any of Ctrl+Alt+Del's side effects in a normal, unlocked session.
