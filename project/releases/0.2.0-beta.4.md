# 0.2.0-beta.4

**Date:** 2026-08-15
**Commit range:** `v0.2.0-beta.2..HEAD` (v0.2.0-beta.3 was never tagged — this release covers
everything since the last tag; release commit included. This version was not tagged either.)

**Included commits** (in git order, `v0.2.0-beta.2` excluded):
1. `docs: point README installer link at v0.2.0-beta.2`
2. `fix: throttle outgoing pointer-move events to ~60Hz`
3. `feat: block duplicate connections to the same host:port`
4. `fix: eliminate per-byte allocation in ZrleDecoder`
5. `release: bump version to 0.2.0-beta.3`
6. `fix: stop sending unpaired modifier-release keysyms on focus loss`
7. `docs: correct the click-flyout limitation — was a MyVNC bug, not wlroots`
8. `release: bump version to 0.2.0-beta.4` (this commit)

## Summary

Fixed the actual root cause behind what had previously been wrongly documented as a
wlr-virtual-pointer-v1 limitation: MyVNC sent a release event for a fixed list of 8 modifier keys
every time keyboard focus changed — regardless of whether they were actually held down — which
corrupted Hyprland's global modifier state. The same cause was behind the repeated "Alt_R"
entries the user observed in wayvnc's own log. Confirmed by the fact that TigerVNC (which does
not have this bug) clicks the same tabs/popup menus without problems against the same server.
The README and the in-app help are corrected accordingly.
