# Proposals

Ideas and designs that are not yet a phase: `YYYY-MM-DD-slug.md` from
[templates/proposal.md](../templates/proposal.md). A proposal is explored here, then the owner
promotes it to a phase (skill `new-phase` links it as the source), defers it or rejects it; the file
stays here with its final `status`. A proposal is never a delivery commitment and never overrides a
shipped contract.
