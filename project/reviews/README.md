# Reviews

Dated assessments of the current state: security posture, CVE reviews, architecture, structure or
function reviews, written by the reviewer role (T3), the `cve-triage` skill or the owner, as
`YYYY-MM-DD-slug.md` (subfolders by topic, such as `security/`) from
[templates/review.md](../templates/review.md). A review is immutable once written; each finding
becomes a ticket, a `review-queue.md` row or an ADR, and the review links to them.
