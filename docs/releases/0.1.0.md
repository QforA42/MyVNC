# 0.1.0

**Datum:** 2026-08-15
**Commit range:** N/A — detta är den första versionsbumpen i repot; ingen tidigare commit fanns
att avgränsa mot. Från och med denna release gäller `BASE_EXCLUSIVE..RELEASE_INCLUSIVE` enligt
[docs/versioning-releases.md](../versioning-releases.md).

## Sammanfattning

Första sammanhållna versionen av MyVNC: en egenbyggd VNC-klient (WPF/.NET, RFB-protokollet
implementerat från grunden) för anslutning till omarchy/Hyprland-hostar via wayvnc, tänkt som
ersättare för TigerVNC.

## Ändringar

Se [CHANGELOG.md](../../CHANGELOG.md#010---2026-08-15) för den fullständiga listan.

## Uppgradering

Ingen tidigare version finns att uppgradera från. Bygg och installera enligt
[README](../../README.md) (eller kör `dotnet build MyVNC.slnx -c Release` och starta via
skrivbordsikonen).

## Risker

- ZRLE-avkodningen är ny i denna version och har verifierats mot protokollspecifikationen samt
  ett rent bygge, men inte fullt ut mot en levande wayvnc-anslutning i det här repot ännu.
- Ingen automatiserad testsvit finns; verifiering är manuell mot riktiga omarchy-hostar.

## Verifiering

- `dotnet build MyVNC.slnx` (Debug) och `dotnet build MyVNC.slnx -c Release` båda gröna.
- Appen startar och stannar uppe utan krasch (rökprovning).
- Manuell funktionstest mot en riktig omarchy/wayvnc-host rekommenderas innan release betraktas
  som fullt verifierad.
