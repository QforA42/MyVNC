## Sammanfattning

Löste den faktiska grundorsaken bakom det som tidigare felaktigt dokumenterats som en
wlr-virtual-pointer-v1-begränsning: MyVNC skickade ett upplösningsevent för en fast lista av
8 modifierartangenter varje gång tangentbordsfokus ändrades — oavsett om de faktiskt var
nedtryckta — vilket korrumperade Hyprlands globala modifierartillstånd. Samma orsak låg bakom
de upprepade "Alt_R"-posterna i wayvncs egen logg som användaren observerade. Bekräftades
genom att TigerVNC (utan denna bugg) klickar samma flikar/popup-menyer utan problem mot samma
server. README och in-app-hjälpen är korrigerade i enlighet med detta.

## Regressionstestning som gjordes inför denna release

- `dotnet build` (Debug + Release) grönt efter fixen.
- **Inte liveverifierat mot en riktig Waybar/Quickshell-flik ännu** — fixen adresserar en
  bekräftad, verklig bugg (loggspammet och den korrumperade modifierartillståndet), men det
  ursprungliga symptomet (klick öppnar ingen popup) har inte omtestats end-to-end sedan fixen
  landade, eftersom de tillgängliga hostarna var upptagna (VS Code öppet på en, en animerad
  låsskärm på den andra) vid tidpunkten för denna release.

## Risker

- Se ovan — betrakta klick-på-flyout-fixen som sannolik men inte slutgiltigt bekräftad tills
  någon faktiskt klickat på en Waybar/Quickshell-ikon i en riktig session efter uppgraderingen.
