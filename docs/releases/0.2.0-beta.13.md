# 0.2.0-beta.13

**Date:** 2026-08-16

## Summary

Reported live: the SSH button on a card disappears right after editing that connection, and
reappears "after a while".

Cause: saving an edit replaces the profile with an entirely new `ConnectionProfile` instance. Both
`IsSshAvailable` and (since beta.11) `IsSessionActive` are `[JsonIgnore]`/runtime-only state — so
they were silently reset to `false` on every edit instead of being carried over, which made the
icon/button state disappear until the next natural recheck (the dashboard regaining focus) set
them again.

Fixed by copying both flags from the old profile to the new one on save, plus an immediate
recheck right after saving — in case the edit actually changed an address, so that a
copied-but-stale value cannot linger.
