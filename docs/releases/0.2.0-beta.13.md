# 0.2.0-beta.13

**Datum:** 2026-08-16

## Sammanfattning

Rapporterat live: SSH-knappen på ett kort försvinner direkt efter att man redigerat den
anslutningen, och dyker upp igen "efter ett tag".

Orsak: att spara en redigering ersätter profilen med en helt ny `ConnectionProfile`-instans.
Både `IsSshAvailable` och (sedan beta.11) `IsSessionActive` är `[JsonIgnore]`/enbart
runtime-tillstånd — de nollställs alltså tyst till `false` vid varje redigering istället för att
följa med, vilket gör att ikonen/knapptillståndet försvinner tills nästa naturliga omkontroll
(dashboarden återfår fokus) sätter dem igen.

Åtgärdat genom att kopiera över båda flaggorna från den gamla profilen till den nya vid
sparande, plus en omedelbar omkontroll direkt efter sparandet — ifall redigeringen faktiskt
ändrade en adress, så att ett kopierat-men-inaktuellt värde inte kan hänga kvar.
