# 0.8.1

**Date:** 2026-08-18
**Commit range:** `v0.2.0-beta.16..v0.8.1` (release commit included).

**Included commits** (in git order, `v0.2.0-beta.16` excluded):
1. `fix: serialize RFB connect/disconnect and move clipboard reads off the UI thread`
2. `feat: pin the session topbar with a Left Ctrl triple-tap`
3. `feat: replace About/Help/Settings/Add dialogs with full-page views`
4. `docs: document fullscreen, topbar-pin, search/pin, duplicate-guard, reconnect cap, and Wake in README`
5. `release: bump version to 0.8.1` (this commit)

## Summary

Two separate threads land in this release.

The first is a real stability fix that had been sitting unapplied in the working tree: a quick
tab close in the middle of an ongoing `ConnectAsync` could race `DisconnectAsync` over the same
`RfbClient` field, and a reconnect attempt could overwrite `_client` without disposing the old
one — a leaking half-open socket per attempt, exactly the shape of the earlier unsolved memory
growth/duplicate connection incident. Connect/disconnect are now mutually exclusive via a
semaphore, and a tab close aborts an ongoing connection attempt immediately instead of only
cancelling the wait before it. Clipboard reads were also moved off the UI thread —
`Clipboard.GetText()` can block for a second or more under contention, and was previously called
synchronously from a raw Win32 window-message hook, which froze the whole app.

The second thread is a UI rework: the dashboard's four secondary views (About, Help, Settings,
New/Edit connection) went from floating dialogs on a dimmed backdrop to full-page views sharing
the same surface/margins as the host list, with a back arrow instead of an X close button. At the
same time the session window got a new way to pin the toolbar visible (triple-tap Left Ctrl, as
an alternative to holding Right Ctrl), and the Help page got a keyboard-shortcut table, a guide
for two common wayvnc setups (external monitor vs. built-in screen, documented from
<hostname>/<hostname>'s actual configuration), and a rewritten "known limitations" list that only
contains what is actually still true today. The README was updated at the same time with several
already shipped but undocumented features (fullscreen, search/pin connections, the
duplicate-connection guard, the reconnect cap, the Wake button).

## Regression testing done for this release

- `dotnet build` (Debug + Release) green after every commit in this release.
- Manual test run of the app (Debug build) after the UI rework — About/Help/Settings/New
  connection navigate correctly as pages with a back arrow.
- Installer built and installed (silently) from the Release build; the app starts and runs the
  new code.
- **Not live-verified**: the connect/disconnect race fix addresses a confirmed code path
  (verified via code review), but the original incident case (memory growth/duplicate connection)
  has not been retested end-to-end against a real omarchy host since the fix landed.

## Risks

- See above — consider the connect/disconnect race fix likely but not conclusively confirmed
  against the original incident case until it has been observed again (or fails to recur) in
  production.
- The version number jumps from `0.2.0-beta.16` to `0.8.1` at the user's explicit request — no
  `0.3.0`–`0.8.0` has ever existed or been tagged.
