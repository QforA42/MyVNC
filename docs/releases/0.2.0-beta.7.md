# 0.2.0-beta.7

**Datum:** 2026-08-15

## Sammanfattning

Samma buggklass som klickfixen i beta.6, upptäckt direkt efter: mushjulet gjorde ingenting i en
session. `RemoteFramebufferControl` prenumererade på det bubblande `MouseWheel`-eventet, men
`ScrollHost` (`ScrollViewer`n som omsluter framebufferbilden) konsumerar `MouseWheel` för sin
egen scrollning och markerar det som hanterat innan det någonsin bubblar upp till kontrollen.

Bytte till `PreviewMouseWheel` (tunnlande), samma mönster som musknappsfixen. Markerar även
eventet som hanterat efteråt så att den lokala vyn inte scrollar dubbelt i "verklig storlek"-läge
(där `ScrollHost` faktiskt har något att scrolla).

Liveverifierat direkt av användaren mot en riktig session.
