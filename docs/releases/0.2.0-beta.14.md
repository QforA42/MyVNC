# 0.2.0-beta.14

**Datum:** 2026-08-17

## Sammanfattning

Rapporterat live: appen "hängde" igen. Loggen visade en flik som fortfarande försökte
återansluta till en död adress (fel port, ingenting lyssnade där) efter 55+ försök och gott och
väl över en timme — och, fortfarande oförklarat, en ANDRA, oberoende återanslutningssekvens för
samma flik som körde parallellt (två olika försöksräknare som klättrade samtidigt i loggen,
bekräftat via `grep` på "attempt 1)"-rader vid tre olika tidpunkter utan att anslutningen någonsin
faktiskt lyckats). Grundorsaken till dubbelloopen är inte hittad än, men oavsett orsak var det
uppenbart fel att låta återanslutning fortsätta i all oändlighet mot ett mål som aldrig kommer
svara.

Åtgärdat pragmatiskt: ge upp och stäng fliken automatiskt efter 3 misslyckade
återanslutningsförsök, istället för att fortsätta i all oändlighet. Begränsar skadan oavsett vad
som faktiskt orsakar dubbelloopen.

## Risker

Grundorsaken till den observerade dubbla återanslutningsloopen är inte fastställd — om den
återkommer bör den nu åtminstone vara självbegränsande (flikar stängs efter 3 försök istället för
att köra i evighet), men det underliggande "varför två loopar" är fortfarande okänt.
